ListenFree 0.3.3

新增
- 主页面支持自选本地视频及 Wallpaper Engine 视频壁纸背景，静音循环播放，窗口隐藏时暂停。
- 自动识别 Steam 多个库中的视频壁纸，以缩略图弹窗选择，支持搜索、刷新和手动指定目录。
- 自选背景下方显示相应选择项；选择后说明文字显示文件路径或颜色代码。
- 检查更新接入 WinSparkle：查看新版说明、下载进度、取消下载和确认安装，更新文件来自 GitHub Release，并验证 EdDSA 签名。
- 安装版原位升级；便携版更新保留原目录、便携模式及 data 数据。

调整
- 下载歌曲时不再自动展开下载记录面板，可从下载按钮手动打开。

说明
- Wallpaper 当前支持本地视频项目，不运行场景、网页或应用类壁纸。
- 仅手动检查更新，不在后台定期检查或自动下载。
- 0.3.2 及更早版本需先手动安装本版；后续版本可在“设置 → 关于 → 检查软件更新”下载更新。
