ListenFree 0.3.2 · Windows x64

更新内容

• 在线播放：修复特定目录或请求长度导致音源进程退出、在线歌曲无法播放的问题；改善启动与重连恢复，连接故障时保留选中的歌曲，音源管理增加“重新连接”。
• Windows 媒体控制：接入系统媒体卡片，显示歌曲、歌手、封面和进度，支持播放、暂停、停止、上一首、下一首及进度跳转。
• 内存：减少封面解码、图片纹理和资料库模型的重复占用；限制大图同时解码的数量，及时释放后台任务结果，并按预算回收页面缓存。
• 动态封面：使用有上限的视频帧队列，保留暂停、首帧和不支持格式的回退行为。
• 专辑轮转：只创建焦点附近最多 9 张卡片，主封面与倒影复用图片缓存；小封面保留原始像素，避免不必要的放大解码。
• 搜索：修复白色输入背景下文字不可见的问题，输入及选中文字使用清晰配色。
• 镜台：改进镜头衔接、空间点阵装饰、近景文字清晰度，保持歌词与装饰的相机一致。
• 浮名：增加字号层次与横竖混排，改善聚焦、竖屏阅读和强调效果。
• 歌词搜索：各来源独立返回结果，支持来源筛选、进度与停止搜索，修复多次搜索卡住及部分歌曲召回不稳定。
• 资料库：修复文件及子目录删除后的列表同步；手动从资料库移除后不会被自动监控立即加回，主动重新扫描可重新加入。

安装与升级

安装版运行 ListenFree-0.3.2-windows-x64-Setup.exe。
便携版完整解压 ListenFree-0.3.2-windows-x64-Portable.zip 后运行 listenfree.exe，个人数据保存在同目录 data。
如需沿用旧便携版资料库和设置，请先退出旧程序并备份，再将旧版 data 文件夹复制到本版程序目录。
程序包不含个人资料库、账号凭据、用户音源脚本、历史或音乐文件。

音源需自行导入。酷我专用音源只支持酷我，播放网易云等平台歌曲需选择支持相应平台的音源。

本版沿用已有性能报告，没有重新执行整套内存基准，暂不承诺新的整体内存降幅。
Windows 11 本地验证；本轮未在 Windows 10 上重新验收。
